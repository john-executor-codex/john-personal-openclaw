# John-IA — OpenClaw Personal Config

Configuração pessoal do agente **JOHN-IA** usando o framework OpenClaw, voltada para automação BIM com Inteligência Artificial e Revit.

## Sobre o Projeto

O **JOHN-IA** é um agente de IA desenvolvido para atuar como assistente especialista em **BIM (Building Information Modeling)**, integrando o GPT Builder da OpenAI com ferramentas de automação do Revit via FastAPI.

Este repositório contém a configuração pessoal do OpenClaw utilizada pelo agente JOHN, incluindo instruções, contexto e parâmetros de comportamento.

## Stack e Tecnologias

- **OpenClaw** — Framework de configuração de agentes IA
- **GPT Builder** (OpenAI) — Plataforma base do agente
- **Revit / BIM** — Domínio de especialização
- **FastAPI** — Backend da API de integração
